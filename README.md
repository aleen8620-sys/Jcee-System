# نظام تسجيل الزوار والتذاكر — خطوات الرفع

## الملفات

```
index.html        صفحة التسجيل العامة
badge.html        بطاقة الدخول القابلة للطباعة
api/pay.js        إنشاء فاتورة الدفع  (خادم)
api/return.js     التحقق من الدفع وإصدار الرمز (خادم)
```

## 1 · GitHub

ارفع الملفات الأربعة إلى مستودع جديد، **مع الحفاظ على مجلد `api`**:

- `index.html` و `badge.html` في الجذر
- `pay.js` و `return.js` داخل مجلد اسمه `api`

> في GitHub: Add file → Upload files → اسحب مجلد `api` كاملاً بالفأرة، لا ملفاته منفردة.

## 2 · Vercel

Add New → Project → اختر المستودع → **Deploy**.

لا تغيّر أي إعداد بناء — Vercel يتعرّف على مجلد `api` تلقائياً.

## 3 · متغيرات البيئة — الخطوة الحاسمة

Vercel → المشروع → **Settings → Environment Variables**، وأضف ثلاثة:

| الاسم | القيمة | من أين |
|---|---|---|
| `SUPABASE_URL` | `https://wozvvtyurxipbejwczwc.supabase.co` | جاهز |
| `SUPABASE_SERVICE_KEY` | مفتاح `service_role` | Supabase → Settings → API |
| `MOYASAR_SECRET_KEY` | `sk_test_...` | مُيسِّر → المطورون → المفاتيح |

اختر **Production** و **Preview** و **Development** لكل متغيّر.

> **هذان المفتاحان سرّيان.** لا يوضعان في أي ملف ولا يُرفعان على GitHub.
> يعيشان في Vercel وحدها، ولا يصل إليهما المتصفح إطلاقاً.

**ثم أعد النشر:** Deployments → آخر عملية → ⋯ → **Redeploy**.
المتغيّرات لا تُقرأ إلا عند البناء، فبدون إعادة نشر تبقى الدالة بلا مفاتيح.

## 4 · التجربة

افتح `https://<مشروعك>.vercel.app/?e=demo-2027`

| الاختبار | المتوقع |
|---|---|
| تذكرة عادية (مجاناً) | رمز فوري + بطاقة |
| المسار السريع (150 ريال) | تحويل لصفحة دفع مُيسِّر |
| نفس الجوال مرتين | «أنت مسجّل مسبقاً» + نفس الرمز |

### بطاقات الاختبار في مُيسِّر

| الشبكة | الرقم |
|---|---|
| مدى | `4201320111111010` |
| فيزا | `4111111111111111` |
| ماستركارد | `5421080101000000` |

تاريخ انتهاء مستقبلي وأي CVV من ثلاثة أرقام.

## 5 · التحقق من أن الدفع تمّ فعلاً

Supabase → **Table Editor** → جدول `orders`:

- `status = paid` و `provider_ref` فيه معرّف الدفعة
- وفي جدول `visitors` صف جديد بنفس `order_id`

إن بقي `pending`، افتح Vercel → **Logs** وابحث عن `moyasar` لترى سبب الرفض.
